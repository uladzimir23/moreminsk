# Skill: UI Primitives

> Не изобретать контролы заново. У проекта один визуальный язык — каждый новый
> контрол должен совпадать с уже существующим. Круглая стрелка «от балды» = баг.

## Правило №1 — сначала найди эталон

Перед тем как сверстать стрелку / иконочную кнопку / пейджер — **найди, где это
уже есть**, и переиспользуй стиль (миксин или копию токенов), а не придумывай свой.
Грепни по `src/widgets` / `src/shared`, посмотри главную (`fleet-showcase`,
галерея, отзывы).

## Стрелки каруселей / пагинации — `@include nav-arrow`

Эталон: `src/shared/design-system/mixins/_mixins.scss` → `@mixin nav-arrow`.
Используется в `fleet-showcase-section` (главная) и `fleet-catalog` (карточки яхт).

- **Квадратные** (`border-radius: 0`) — НЕ круглые. Совпадает с гео-языком кнопок.
- Стеклянный фон `--media-glass-bg`, хайрлайн `--media-hairline-strong` → акцент
  `--color-accent` на ховере; иконка `--on-media`.
- Шеврон — **inline `<svg>`** (`<path d="M15 18l-6-6 6-6"/>` prev / `M9 18l6-6-6-6` next),
  не lucide, чтобы работал `@include chevron-fly("prev"|"next")` на `svg` при ховере.
- Применение:
  ```scss
  .navPrev,
  .navNext {
    @include nav-arrow; /* + позиционирование */
  }
  .navPrev:hover svg {
    @include chevron-fly("prev");
  }
  .navNext:hover svg {
    @include chevron-fly("next");
  }
  ```
- Центрируй позиционированную стрелку через `margin`, не `transform` —
  `nav-arrow` тянет `btn-press` (`:active { transform: scale }`), они подерутся.

## Геометрия (ADR/база проекта)

- **CTA — квадратные** (`border-radius: 0`). Пилюли/иконки-капсулы — **полностью
  круглые** (`999px` / `50%`). Промежуточных скруглений у интерактива нет —
  иначе ломается язык. Стрелки идут по квадратному регистру (см. выше).

## Кнопки

- Главный CTA — `@include btn-cta` (Signature·settle: комета → спот/тильт за
  курсором + рост + парус по низу). Не верстать CTA вручную.
- Ghost/outline — `@include btn-fill`; «прилив» — `@include btn-tide`. Нажатие —
  `@include btn-press`.

## Точки-пейджеры

Маленький `<button>` с `background-clip: content-box` + padding для тач-таргета,
активная — `--color-on-image` + `scale`. См. `FleetCatalog.module.scss` → `.dot`.

## Чек перед коммитом нового контрола

1. Нашёл эталон и переиспользовал миксин/токены? (не хардкод-гексы, не свой radius)
2. Форма совпадает с гео-языком (квадрат CTA / круг пилюля)?
3. Работает в обеих темах (`--media-*` / `--on-media` / `--color-*`)?
4. `prefers-reduced-motion` гасит анимацию?
